# Simaliba Lead Demo

Publikus GitHub Pages demo az OpenClaw lead generator mini projekthez.

## Mit mutat?

- Egy lead adatlapot
- Egy HTML ajanlat oldalt
- Egy kattinthato PDF ajanlatot
- Egy nem kikuldott email draftot

## GitHub Pages beallitas

1. Hozz letre egy publikus GitHub repot, peldaul `simaliba-lead-demo-public` neven.
2. Pushold ezt a repot.
3. GitHubon: Settings -> Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, folder: `/docs`.

Publikus URL forma:

```text
https://<github-user>.github.io/simaliba-lead-demo-public/
```

## Fontos

Ez csak training/pilot demo. Az email nincs kikuldve, a lead es az ajanlat emberi jovahagyasra var.
